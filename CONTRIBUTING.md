# Contributing

Thanks for your interest in [three-player-controller](https://github.com/hh-hang/three-player-controller). Bug reports, ideas, and pull requests are welcome.

Before larger changes, please open or search an [Issue](https://github.com/hh-hang/three-player-controller/issues) first.

## Development

```bash
git clone https://github.com/hh-hang/three-player-controller.git
cd three-player-controller
npm install
npm run dev
```

Open `http://localhost:5173/`.

- Library code: `src/`
- Demos: `example/`

Use `npm run build` to verify the library builds.

## Pull Requests

1. Branch from `master` and keep the PR focused
2. Make sure related demos work under `npm run dev`, and `npm run build` succeeds
3. Update `README.md` / `README_En.md` if public APIs change
4. Describe the change and how you tested it
